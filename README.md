
# Netflix Audience Segmentation Analysis

## Project Overview
This project analyzes Netflix content ratings to understand audience segments and content targeting strategies.

## Objectives
- Group content by audience ratings.
- Identify dominant audience categories.
- Compare Movies and TV Shows by ratings.
- Visualize audience distribution.
- Develop audience-focused recommendations.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Analysis
- Audience Rating Distribution
- Top Audience Categories
- Movies vs TV Shows Comparison
- Rating Percentage Analysis

## Business Insights
The analysis identifies dominant rating categories and compares rating patterns between Movies and TV Shows.
